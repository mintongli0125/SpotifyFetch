## Instructions

If you're using Spotify PC / Web:

- Click on a track, or Ctrl+A to select all tracks in a playlist.
- Press Ctrl+C – now you have the song link(s).
- Paste into SpotifyFetch.
- SpotifyFetch returns song title & artist in plain text!
